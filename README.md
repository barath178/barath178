## 🚀 Featured projects

### 🌾 [AeroAgro AI: Panchayat-level weather downscaling](https://github.com/barath178/panchayat-weather-downscaling)
Turns 12–25 km forecasts into ~1.2 km village-level weather using terrain physics (lapse rate, cold-air drainage, orographic lift), then converts it into farmer advisories: spraying, irrigation, pest alerts and PMFBY crop-insurance evidence.
`TypeScript` · [Live site](https://aeroagro.vercel.app)

### 🛢️ [Baghewala CSS + SRP Digital Twin (SIH26120)](https://github.com/barath178/sih26120-digital-twin)
A well-to-surface digital twin for heavy-oil wells that couples Cyclic Steam Stimulation with sucker-rod pumps and searches both settings together. Engineers approve every change. Built on synthetic data, with 92 tests.
`Python` · `React` · `Docker` · [Live demo](https://sih26120-digital-twin-lilac.vercel.app)

### 💪 EMG Gesture Classifier *(private)*
Real-time hand-gesture recognition: BioAmp EXG Pill → Arduino (500 Hz) → filtering → feature extraction → Random Forest / SVM.
`Python` · `Arduino`
